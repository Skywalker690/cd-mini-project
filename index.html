THE LANGUAGE REFERENCE
A small language, explained.

    
StringLang has one string type and one global scope. Statements run from top to bottom after the entire program passes compilation.

      
The essentials
  • Declare with string name; or string name = expression;.
  • Assign with name = expression;. Concatenate with +.
  • Use print(expression); for output. Each print adds a newline.
  • Use double quotes, semicolons, parentheses, and // comments.
  • Names are case sensitive. Declare and initialize a variable before reading it.

      
Escape sequences
\n Newline\t Tab\r Carriage return\\ Backslash\" Double quote
Raw line breaks, invalid escapes, and missing closing quotes are lexical errors. Empty strings are valid. Numbers and single-quoted strings are outside this language.

      
The predictive grammar
Program  → List
List     → Stmt List | ε
Stmt     → Decl | Assign | Output
Decl     → 'string' id Init ';'
Init     → '=' Expr | ε
Assign   → id '=' Expr ';'
Output   → 'print' '(' Expr ')' ';'
Expr     → Term ExprTail
ExprTail → '+' Term ExprTail | ε
Term     → literal | id | '(' Expr ')'
Removing left recursion makes recursive descent possible. Left factoring gives declarations a shared prefix. The final grammar is LL(1). The expression loop preserves left associativity in the AST.

      
What each phase checks
Lexical analysis
Recognizes tokens, validates literals, and decodes escapes.
Syntax analysis
Checks the grammar and builds an abstract syntax tree.
Semantic analysis
Checks declarations, initialization, duplicate names, and string lengths.
Demonstration limits: 65,535 source code units, 4,096 tokens, 256 variables, 63 characters per name, 1,023 code units per string, and 128 levels of nesting. String lengths and columns use JavaScript UTF-16 code units.
